## 構成

提案書 02節「画面イメージ」の保育園サイト トップの11ブロックを、そのままの順で実装している。
**構成は提案書と一致させること。**ここでずらすと「間取りは決まった」という前提が崩れる。

1. ヘッダー（ロゴ／ナビ／見学CTA）
2. ヒーロー（見出し・写真）
2.5 ロゴ（**案Cのみ**。下記）
3. 帯（開園時間・施設数・対応言語）※提案書には無い追加分
4. 選ばれている3つの理由
5. かみのての保育 ― 大切にしていること
6. 園のご紹介（かみのて保育園／かみのて今渡保育園）
7. 病児保育のご案内 → 専用ページ
8. 入園案内・保育料（企業主導型／提携企業）
9. かみのてで働く人 → 採用ページ
10. お知らせ・園の日記
11. 見学・お問い合わせ／フッター

ナビとフッターは、提案書の**保育園サイト ページ一覧（全11ページ）すべてに導線がある**状態に
してある。「私たちについて」と「園での生活」はトップに対応するブロックが無い独立ページなので、
リンクだけ置いている（`href="#"`）。
**セクションラベルに「わたしたちについて」を使ってはいけない。**
提案書では「私たちについて」が別の独立ページ（理念・園長メッセージ・法人概要）なので、
4番目のブロックのラベルは「かみのての保育」にすること。

ナビとロゴとCTAは一列に入らなくなると折り返して崩れるので、幅を切ってメニューごと畳んでいる。
**畳む幅は案ごとに違う**（ナビの文字数と実ロゴの幅で決まる）:

| | 畳む幅 | 崩れ方 |
| --- | --- | --- |
| 案A | `max-width:1100px` | 園名が「かみの…」と省略される |
| 案B | `max-width:1000px` | ナビが2行に折り返して園名に重なる |

**この崩れは `scrollWidth` の検査では出ない**（折り返しははみ出しではないため）。
ヘッダーは幅を変えて目視すること（`kmtest/_head.html?p=n2/plan-a.html&w=901,1000,1100,1101`）。
**畳む幅の指定は、スマホ用のブロック（最大900px）とは別の `@media` に分けてある。**
まとめると 900〜1100px がスマホ用の1カラムになってしまう。

## 実ロゴ（2026-08-22 追加）

顧客からいただいた かみのて保育園のロゴ（円形バッジのスクリーンショット 329×228）から、
`img/` に2枚を起こしてある。**作り直すときは `python3 ~/kmtools/mklogo.py`**
（元画像は `~/kmtools/logo-src-nursery.png`、Pillow が入らないので `~/kmtools/png.py` の自作デコーダを使う）。

| ファイル | 中身 | 置いている場所 |
| --- | --- | --- |
| `img/logo-mark.png` | 文字（かみのて保育園）を消して絵柄だけにしたもの 313×192 | 案A・案Bのヘッダー |
| `img/logo.png` | 文字入りのまま 313×201 | 案Cのヒーロー直下 |

- **ヘッダーには文字を消したほうを使う。**隣に「かみのて保育園」と書いてあるので、
  文字入りだと園名が二重になる。**放課後等デイの `logo-mark.png` と同じ考え方。**
- 文字は左右の手の内側に収まっているので、**矩形1発（x 80〜248 / y 0〜75）で切り出せる**。
  放デイのように二段構えにする必要はなかった。
- **横長なので `height` で指定する**（PC 52px／スマホ 38px）。`width` を決め打ちすると潰れる。
- **背景の白を透明にしてあるので、手のひらのハートと顔の白も抜ける。**
  濃い色や写真の上に置くと地色が透けて読めなくなる（実際に試した）。
  **必ず白〜ごく薄い面の上に置くこと。**フッターは地色が濃いので置けない
  ＝仮マークごと外して名前だけにしてある。
- **案Cは 2026-08-22 に作り直して白い帯のヘッダーになった**ので、案A・案Bと同じく
  ヘッダーにも文字なしを置いている。写真のすぐ下の白い `.logos` はそのまま残し、
  そちらは文字入りのほう＝帯のマークと文字が二重にならないようにしてある。

## デザインの意図

### 色（2026-08-20 変更：パステルブルー）

**主色はパステルブルー。ユーザーから色見本 `#dcedf8` の指定を受けた。**
見本はとても淡く、そのままでは文字にも線にも使えないので（白地で読めない）、
**「濃くしていい」との指示を受けて濃い段を足し、3案とも同じ階調にしてある。**

- `--blue` #5fa8cc（面・線・ロゴ）／ `--blue-d` #2c6f92（文字。白地でコントラスト4.9）
  ／ `--blue-soft` #dcedf8（薄い面＝いただいた見本そのまま）
- **薄いブルーを文字色に使わないこと。**読めない。文字は `--blue-d`。
- 案Cだけトークン名が `--brand` 系（`--brand` / `--brand-d` / `--brand-soft`）。
  中身は上と同じ値。

**地色も薄い青にしてある**（2026-08-20・「もっとパステルブルーを前面に出したい」）。
**いただいた #dcedf8 を全面に敷くのは濃すぎる**（面積が大きいと重く、白いカードとの
差が消えて、CTAのオレンジともぶつかる）。**4段のはしごにして面積で振り分ける**:

| 段 | 色 | 使うところ |
| --- | --- | --- |
| 1 | #fff | カード（写真・情報が乗る面） |
| 2 | #eef7fd | 地色（`--ground`。案Bは `.head` の半透明も同じ色に） |
| 3 | #dcedf8 | 帯のセクション＝いただいた見本（案A `--cream` / 案B `--cream` / 案C `--paper`） |
| 4 | #cbe2f3 | 帯の上に置く面・ピル（`--blue-panel`） |

**トークン名は履歴のまま `--cream` / `--paper` を使っている**（中身は薄青）。
名前で暖色だと判断しないこと。**4段目が要る理由**は、帯のセクションの上に
3段目と同色の面を置くと消えるため（案Cの `.notice` と `.steps li` が実際に消えた）。
最初 #f6fbfe で試したが**白と見分けがつかず**、一段上げて #eef7fd にしている。

**CTAはグループ共通のオレンジ**（`#ef8b4c` / グラデーションは `#f8b478→#f19a4d`）。
主色を青にしたので、ボタンまで青いと押す場所が沈む。放課後等デイサイト
（パステルグリーン＋オレンジ）と対になり、**2サイトで同じ配色の考え方**になる。

**副の色でぶつかったところ**（青が主色になったことで起きた玉突き）:
- 案A：病児保育のパネルが青緑（#eef7f6）で主色と同系に沈むので暖色に振り替えた。
  「別の用件だと分かるように色を分ける」という当初の意図を保つため。
- 案B：副の「空」#8ec9dd を廃止。数字の3色目はたまご色、お知らせのタグは桃に。
- 案C：副の「空」を廃止し、数字の3色目をオレンジに。あわせて `.tab-pink` は
  実態と合わなくなったので `.tab-soft` に改名した。

**元はアプリコット／オレンジだった**（さらに前はミント #7fc6a0）。
放デイのパステルグリーンと見分けるためにミントから振り替えた経緯があるので、
**ミントにも戻さないこと。**パステルブルーは放デイのグリーンとも十分に離れている。

### 共通の設計言語

**かみのてKIDSサンプル（`~/kids-support-sample`）とテイストを揃えている。**
放課後等デイサイト（`~/kaminote-day-design`）とも、色以外はすべて共通にしてある。
同じグループだと分かるようにするため。

- 書体は Zen Maru Gothic を全面に。英字は Baloo 2（`.en`）
- ヒーローは**写真を全面背景にしてクリームのグラデーションを重ねる**方式。
  中央寄せ・ピル型バッジ・見出しの一部にマーカー（`.hl`）・2行目を主色（`.warm`）
- ヒーロー下の波型SVG（`.wave`）で次のセクションへつなぐ
- セクションラベルは絵文字＋主色の小見出し、見出し下に英字（`.sec-title .en`）
- 丸いピル型ボタン、やわらかい影、大きめの角丸
- スクロールで要素がふわっと出る（`.reveal` ＋ IntersectionObserver）

`prefers-reduced-motion` を指定している人にはアニメーションを出さない。

**ヒーローに絵文字は入れない。** サンプルには浮遊する絵文字の飾り（🌷⭐🧸🎈）があり
一度は入れたが、指示により削除した。CTAボタンに付けていた 🌱 も同時に外している。
ヒーロー以外のセクションラベルの絵文字はそのまま残している。

## 確認済みの表示

Edge ヘッドレスで検証。横スクロールは 390 / 489 / 768 / 1200px すべてで発生なし。
390px は Edge の最小ウィンドウ幅（約477px）に丸められるため、
390px 幅の `<iframe>` に入れて内側から `scrollWidth` を測っている。

`.reason` はスマホで「アイコン＋本文」の横並びにするが、
見出しと本文を `.reason-body` でくくらないと2カラムグリッドの別セルに落ちて
はみ出す。まとめてあるのはそのため。

### 2026-08-23 追記：6案すべてを分割版にした

試作（案Bのみ）がよいと確認が取れたので、**保育園3案・放デイ3案すべて**を
同じ形に分けた。生成は `python3 ~/kmtools/split_plan.py <nursery|day> <a|b|c>`。

- 保育園: `a/` `b/` `c/`（トップに残すのは「3つの理由」）
- 放デイ: `a/` `b/` `c/`（トップに残すのは「こんな方へ」）
- **提案資料のリンクは分割版（`…/kaminote-design/b/` の形）に差し替え済み。**
  1枚もの `plan-*.html` は残してあるが、資料からはもう参照していない。

**split_plan.py の勘所**:
- **id の無い節を落とさないこと。** 放デイには id 無しの節（多言語での支援）がある。
  節の数を数えて突き合わせ、表記が決まっていない節があれば止まるようにしてある。
- **案Cはヘッダー右に丸い「採用情報」バッジがある。** メニューにも入れると二重に出るので、
  `.pill-recruit` があるときは nav から recruit を外している。
- 下層用の部品（パンくず・入口カード・お知らせ一覧）は**トークン名に依存させない**。
  案ごとに `--blue-d` / `--brand-d` / `--pg-deep` とバラバラなので、`--x-accent` に寄せ、
  面の色は `rgba(0,0,0,.035)` で作る。どの配色でも成立する。

### 2026-08-24 スマホのメニューボタンを動くようにした

**それまでハンバーガーは押しても何も起きなかった。** ボタンとCSS（畳んだら `.gnav{display:none}`）

- **400px以下**: もう一段（ロゴ30px・園名13px・ボタン10px）。360〜375px の端末向け。
- **放デイはさらに一段**（園名12px・ロゴ28px）。「かみのてKIDS・SMILE」は
  「かみのて保育園」より4文字ぶん長く、同じ設定では収まらない（`HEAD_CSS` の `SP_NAME`）。
- **★言語ボタンの文言は訳さないようにした。** 「日本語 / English / Português」と
  それぞれの言語で書いてあるのが切り替えの作法で、英語版で「Japanese」と出ると
  自分の言語を探しにくいうえ横にも長い。`i18n_apply.py` が `.lang` の中の
  `data-i18n` を落としている。

**★同じ幅を狙う @media は「狭いほう」を後ろに書くこと。** 最初は 400px の指定を
560px の前に置いてしまい、560px の指定に上書きされて**まったく効いていなかった**
（画面を見て「変わっていない」と気づいた）。案ごとの `HEAD_CSS` も同じ理由で
EXTRA_CSS の末尾に移した。

**残っている制約**: 320px（旧世代の小型端末）では、英語・ポルトガル語のときに
名前が省略記号で切れる。ポルトガル語の「Kaminote KIDS e SMILE」が長いため。
横スクロールは出ない。

### 2026-08-25 言語の切り替えを「ボタン1つ＋一覧」にした

3つ並べるピル型（日本語 / English / Português）をやめ、**地球のアイコン＋「言語」の
ボタン1つ**にして、押すと一覧が開く形にした。**タガログ語・ビサヤ語を足す前提**での変更。

- **言語を増やすときは `split_plan.py` の `LANGS` に1行足すだけ**
  （`LANGS = [("ja","日本語"), ("en","English"), ("pt","Português")]`）。
  メニューのHTMLはそこから組み立てている。訳は
  `~/kmtools/i18n-manual-<site>.json` に足す（未訳はその言語でも日本語のまま出る）。
- **ボタンは1つなので、言語が何個になってもヘッダーの幅は変わらない。**
  ピル型のままだと1言語増えるごとに約70px伸び、スマホでは園名を押し出していた。
- **ボタンの文言「言語」は訳す**（Language / Idioma）。**言語名そのものは訳さない**
  （それぞれの言語で書いてあるのが切り替えの作法）。`i18n_apply.py` が
  `data-lang` の付いた button から `data-i18n` を落としている。
- runtime（開閉と切り替え）は **`~/kmtools/i18n_runtime.js` に1本化**した。
  以前は生成済みの `i18n.js` から切り出して使い回していたので、直したい処理が
  2リポジトリに散らばっていた。
- 一覧を開くとスマホのメニューは閉じる（同じ場所に2枚重ならないように）。
- **★古いピル型の指定 `.lang button.on{background:主色;color:#fff}` が一覧の項目にも
  効いてしまい、選択中の行が「濃い帯に白文字」で読めなくなっていた。** 打ち消してある。

**畳む幅を6案とも測り直した。** 分割版に言語ボタンが戻ったぶん、ヘッダーは約90px
広くなる。**それまでの値は言語ボタンが無い状態で測ったもので、足りていなかった。**
あわせて**分割版のヘッダーの頭打ちを 1440px に広げた**（1280px のままだと、
画面をいくら広げても園名が省略されたままになる）。
